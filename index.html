go-order-api

API RESTful de gerenciamento de pedidos em Go — arquitetura limpa, zero frameworks web, pronta para produção.

Stack

Tecnologias utilizadas neste projeto.

🐹

Go 1.27

Linguagem principal. Binário estático compilado com CGO_ENABLED=0, distribuído em imagem distroless.

linguagem
🌐

net/http + ServeMux

Servidor HTTP da biblioteca padrão — sem framework web externo. Middlewares compostos manualmente.

http
🐘

PostgreSQL + pgx/v5

Banco relacional com driver nativo, pool de conexões, migrations automáticas na partida e lock consultivo.

database
🔑

JWT RS256

Autenticação stateless com assinatura assimétrica. Validação de audience e issuer obrigatória em produção.

auth
🐇

RabbitMQ

Mensageria para eventos order.status.changed. Worker independente consome a fila com retry e DLQ.

messaging
📧

SMTP

Envio de e-mails transacionais pelo worker. STARTTLS obrigatório em produção. Mailpit para desenvolvimento.

email

Destaques

Práticas e garantias implementadas.

🏛️ Arquitetura Limpa

Domínio puro, portas declaradas pelo consumidor, adaptadores intercambiáveis.

🔒 Concorrência Segura

Versionamento otimista, FOR SHARE/FOR UPDATE, índices únicos parciais.

🛡️ Rate Limiting

Limites por usuário, por IP e por tipo de operação (leitura/escrita).

🔍 Busca Avançada

Paginação, ordenação e filtros dinâmicos com 9 operadores.

🧪 Testes em Tabela

Testes de unidade sem infra (store em memória) e integração com PostgreSQL real.

🛡️ PII Protegido

Documento, passaporte e e-mail nunca saem na API nem nos logs.
